# 🧠 Mental Health Text Classification

A Machine Learning project that classifies mental health related text into multiple categories using Natural Language Processing (NLP) techniques.

---

## 📌 Project Overview

Mental health issues such as depression, anxiety, and stress are increasingly discussed online.  
This project builds a multi-class text classification model to automatically detect the mental health category of a given text.

The model is trained using the **Mental Health Corpus dataset** from Kaggle.

---

## 📂 Dataset

- **Dataset Name:** Mental Health Corpus  
- **Source:** Kaggle  
- **Type:** Multi-class text dataset  
- **Columns:**
  - `text` → User statement
  - `label` → Mental health category

## 🤖 Model Details

- Algorithm: **XGBoost Classifier**
- Objective: Multi-class Classification
